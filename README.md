# Fetch

Fetch is a standalone Windows media downloader for KALLOS utilities.

It is separate from KALLOS FLOW and uses this repository's GitHub Releases for in-app updates.

## Supported sources

- Instagram
- YouTube
- Behance
- Vimeo

## Updates

The Windows app checks the latest release in this repository and downloads the `Fetch Setup.exe` release asset when a newer version is available.
